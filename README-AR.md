## ⌨️ اختصارات لوحة المفاتيح

### الاختصارات الأساسية

| المفتاح | الوظيفة |
|---|---|
| `S` | تحديد الآية المركّز عليها أو إلغاء تحديدها |
| `↑ / ↓` | التنقّل بين الآيات، أو بين نتائج البحث، أو بين السور بحسب موضع التركيز |
| `Shift + ↑ / ↓` | تحديد الآيات المتجاورة |
| `Ctrl + Shift + ↑ / ↓` | توسيع التحديد إلى أول السورة أو آخرها |
| `Ctrl + ← / →` | الانتقال إلى السورة السابقة أو التالية |
| `Ctrl + Home / End` | الانتقال إلى أول آية أو آخر آية |
| `Ctrl + C` | نسخ الآيات المحددة |
| `Esc` | إغلاق اللوحة المفتوحة أو إلغاء تحديد الآيات |

### اختصارات إضافية

| المفتاح | الوظيفة |
|---|---|
| `Ctrl + F` | الانتقال مباشرة إلى البحث |
| `Alt + S` | فتح قائمة السور |
| `Alt + B` | فتح قائمة العلامات |
| `Ctrl + ,` | فتح الإعدادات |
| `Alt + T` | التبديل بين المظهر الفاتح والداكن |
| `Alt + H` | فتح دليل الاختصارات |
| `B` | إضافة الآية المركّز عليها إلى العلامات أو إزالتها |
| `M` | فتح صفحة المصحف للآية المركّز عليها |
| `Enter` | فتح النتيجة أو السورة المحددة |
| `← / →` | التنقّل بين صفحات المصحف عند فتحها |

## 🍎 الحواشٍ الحقيقية في Word و InDesign

- 📝 يُدرج النص العربي في سندك، ويوضع المرجع في **حاشية حقيقية** لا في سطر منفصل.
- 🔁 إذا كانت الحاشية موجودة أصلاً، يُحدَّث نصها داخلها بدلاً من إنشاء حاشية جديدة.
- 🖱️ في Word يُحدَّد موضع الإدراج داخل السند؛ وفي InDesign يُوضع مؤشر الكتابة داخل إطار نصي.
- 🔐 عند أول استخدام يطلب macOS الإذن بالتحكم في التطبيق الهدف، وتُدار الأذونات من `System Settings → Privacy & Security → Automation`.
- ⚠️ إن كانت عدة نسخ من InDesign مفتوحة، يتوقف الإدراج لتفادي الخطأ في اختيار النسخة.
- 📄 يُسجَّل نتيجة كل عملية في `logs/footnote-integration.log` داخل مجلد بيانات التطبيق.

- 🌐 إصدار الويب يُخزّن شاشات التطبيق وبيانات السور وفهارس البحث والخطوط والأيقونات بعد الزيارة الأولى.
- 💾 إصدار الماك يقرأ ملفاته من حزمة التطبيق مباشرة، ولا يحتاج service worker أصلاً.
- 🗂️ كل التفضيلات والعلامات وسجل القراءة محفوظة محلياً على الجهاز.
